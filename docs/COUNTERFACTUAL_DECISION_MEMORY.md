# Counterfactual Decision Memory (CDM)

Status: experimental implementation program. The attached master plan is a
proposal, not proof that its 240 tasks have been completed. This file is the
local execution ledger; only tasks with linked code and recorded evidence will
be marked complete.

## Scope

CDM investigates recorded agent decisions by reconstructing an explicitly
supported belief state and comparing a controlled, simulation-only replay
after a declared evidence or policy intervention. It does not edit model
weights, infer physical-world causality, execute real tools, rewrite event
history, or let historical evidence authorize current actions.

Evidence labels remain distinct: `observed` is in the event log;
`supported` is checked by a verifier; `derived` records a declared update;
`used` requires a citation or equivalent instrumentation; `authorized` means
the current gate accepted evidence; `intervened` describes a hypothetical
replay input; `caused_internal_decision_change` is permitted only when a
controlled supported replay changes the internal proposal. None implies a
real-world outcome.

## Architecture and trust boundary

```text
Agent / host
  | recorded events and explicit evidence IDs
  v
Current authorizer ---- current + historical policy ----> Capture
  |                                                   (bounded, read-only)
  |                                                               |
  +--> real ActionGate (unchanged)                       immutable trace
                                                                  |
                                                  intervention overlay
                                                                  |
                                         allowlisted pure simulator only
                                                                  |
                               blinded evaluator <---- proposal trace
                                          |                       |
                                          +---- verifier/certificate
                                                  (no action entitlement)
```

The historical reader is not a permission bypass. Capture must ask current
authorization on every evidence item and use the existing historical contract.
Erasure and withdrawal dominate archived reads. A simulation executor accepts
only registered pure functions, cannot open sockets or invoke subprocesses,
and cannot write outside its scoped temporary directory. Verifier identity is
independent of the simulated agent. Certificates attest only to declared
trace properties and replay checks, never action authority or physical truth.

| Threat | Control | Required negative test |
|---|---|---|
| Poisoned or injected memory | Preserve source IDs; never treat model text as policy; test hostile evidence as inert data | `tests/test_cdm_privacy.py` |
| Historical private data leak | Current and historical authorization, indistinguishable omission | `tests/test_cdm_capture.py` |
| Erasure recovery via checkpoint | Do not retain plaintext; current erasure check before output | `tests/test_cdm_privacy.py` |
| Real side effect during replay | Pure-handler allowlist and no authority-bearing adapter | `tests/test_cdm_replay.py` |
| Forged/truncated replay certificate | Canonical digest, complete trace and independent recomputation | `tests/test_cdm_certificates.py` |
| Cross-tenant or revoked reader | Bind tenant/principal and recheck current access | `tests/test_cdm_capture.py` |

## Version-1 facade (frozen proposal)

All public CDM operations are experimental, bounded, in-process and fail closed.

| Operation | Input | Output / refusal |
|---|---|---|
| `capture` | Fabric, verified principal, explicit evidence IDs, inclusive `known_at`, optional `valid_at`, event budget | Immutable factual trace with authorization result and evidence commitments; refuse invalid/unauthorized/incomplete capture. |
| `restore` | Captured trace, registered updater/policy digests | Reconstructed state and fingerprint; refuse missing or mismatched policy. |
| `intervene` | Trace, evidence ID, operation `suppress` or typed replacement, declared intervention digest | Disposable overlay only; reject unknown IDs, malformed replacements and out-of-scope operations. |
| `replay` | Overlay, pure simulator registry, event budget | Hypothetical proposal trace and status `EXACT`, `APPROXIMATE` or `NON_REPLAYABLE`; never executes action handlers. |
| `evaluate` | Factual and counterfactual proposals, blinded evaluator, optional hidden world label held outside candidate inputs | Separate decision-flip, utility and authority measures; no self-reported outcome is accepted. |
| `certify` | Complete trace, replay result, policy/updater digests, intervention and verifier | Content-addressed replay certificate; verification failure or incompleteness refuses certification. |

Stable error codes: `INVALID_INPUT`, `UNAUTHORIZED`, `ERASED`,
`NON_REPLAYABLE`, `POLICY_UNAVAILABLE`, `BUDGET_EXCEEDED`,
`INTERVENTION_INVALID`, `TRACE_INCOMPLETE`, `CERTIFICATE_INVALID`,
`SIMULATOR_FORBIDDEN`.

## Research protocol

## Belief model assumptions and calibration limits

The current belief updater is a finite binary Bayesian model over an explicitly
provided DAG and conditional-probability tables. Its results are conditional on
that graph, those probabilities, the declared evidence values, and the
same-origin deduplication rule. Conflicting independent sources remain visible
in the trace but are excluded from conditioning because no sensor-dependence
model is registered. A normalized posterior is a property of those assumptions,
not proof that the graph or inputs describe the physical world correctly.

The threshold policy maps the simulated posterior to a diagnostic proposal; it
does not estimate calibrated real-world risk. The battery example is synthetic
and illustrative. No posterior or diagnosis confidence in this implementation
has been calibrated or validated for clinical, industrial, safety-critical, or
other physical decisions. Deployment use requires domain-specific probability
elicitation, calibration data, independent validation, and governance review;
CDM output alone must not be presented as validated real-world confidence.

The primary estimands are: (1) decision flip under a declared intervention,
(2) utility difference under a generated world's hidden structural truth, and
(3) change in authorization verdict under the unchanged current gate. These
are reported separately. Observational exposure, lineage, citation,
authorization, and executed intervention are separate variables.

Required controls include no-op intervention, irrelevant evidence,
independent corroboration, duplicate/copy, delayed observation, policy swap,
full suffix replay, random/recency/influence/dependence selection, and exact
small-N enumeration. Baselines run first on the registered primary metric and
budget. The oracle shares all candidate budgets and mechanisms and differs
only in access to generated hidden truth. Any arm above the oracle invalidates
that run. Use at least five disjoint seeds per family as a minimum, preserve raw
paired outcomes, and report uncertainty, compute, refusals, and limitations.

Synthetic results support claims only within their generated worlds. No result
here implies external validation, official reproduction of published systems,
or improved real-world agent accuracy.

The first generated multi-agent fixtures cover copied-source roots at 2, 3,
10 and 50 agents, decision-time visibility under later conflicting evidence,
and a delayed retraction reaching an offline peer only at explicit sync.
These deterministic traces validate fixture semantics; they do not measure
real federated transport or establish distributed causal completeness.

## Rollback

CDM is additive under `memory_fabric.causal_replay` and is disabled unless an
experimental API is explicitly invoked. If a privacy, erasure, real-side-effect,
forged-certificate, tenant-isolation, or deterministic-fidelity invariant fails,
remove/disable the CDM entry point and keep existing Memory Fabric state and
stable APIs untouched.
