# PR #30 valid-withholding cases

`research/results/pr30-withheld-cases.json` contains a row-level replay of the exact PR #30 candidate benchmark: base commit `79a77f43c9e376968163c2164ee277052ed4117e`, candidate `12c612ea37980f92d206fe2b343b217603d1b3cc`, seeds 101–105, 50 agents, and 100 tasks per seed. It recovers 84 valid-withholding cases from 500 attempts (16.8%), matching the published aggregate and its per-seed counts (10, 15, 19, 21, 19).

Each row records the action target, exact current evidence text, whether the backend held and returned it, blocker reason, oracle value, agent, seed, and task index. Source-file SHA-256 values bind the extraction to the candidate checkout. The PR did not contain a serialized 84-row file; these rows are regenerated by running its exact code and deterministic task schedule.

Reproduce from a clean checkout of the candidate commit with:

```powershell
python -m benchmarks.pr30_case_extractor --source-root <clean-pr30-candidate-worktree> --out research/results/pr30-withheld-cases.json
```

The data is deterministic scripted simulation, not real-model evidence.
