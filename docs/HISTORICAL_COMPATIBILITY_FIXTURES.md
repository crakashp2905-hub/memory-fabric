# Historical compatibility fixture provenance

`tests/data/historical/v0.11.0.db.gz` is an authentic store generated by the
published `v0.11.0` release source tag. Its manifest binds the source commit,
the published wheel and sdist hashes, the compressed fixture hash, and the
uncompressed database hash. `tests/test_historical_fixtures.py` opens the
fixture with the current reader, verifies its event chain, appends current
events without rewriting the old ones, and confirms that tampering is reported
by `doctor`.

The repository currently has one formal GitHub release/tag, `v0.11.0`. The
older `0.2.0` through `0.8.0` compatibility cases in
`tests/test_version_skew.py` are reconstructed by the current test helper; they
are not represented as authentic release artifacts. Changelog schema entries
after `0.11.0` are present in this source tree but have no corresponding
published release artifact here. Keep those provenance distinctions explicit
when adding or reporting compatibility evidence.
