# Capability maturity

Generated by `tools/check_product_claims.py`; keep statuses evidence-bound.

| status | meaning |
|---|---|
| **implemented** | Available in the repository with code, tests and documented limitations. |
| **experimental** | Implemented but explicitly experimental or limited; claims must retain that qualification. |
| **simulated** | Shown only in a scripted or synthetic demonstration; not evidence of real-world performance. |
| **externally_unverified** | Requires independent review, external users, real deployments or other evidence unavailable locally. |

## Inventory

| capability | status | basis and limits |
|---|---|---|
| `memory.write.screened` — Write a memory through the ingest screens | **implemented** | Screens catch known patterns only; a novel injection can pass.; A plausible first claim about something the store has never seen cannot be checked (staging run). |
| `memory.retrieve.governed` — Retrieve with tenant, scope and lifecycle enforced | **implemented** | Lexical ranking by default; recall@1 is low when many notes share a tag (research/results/product-bench.md). |
| `memory.provenance.inspect` — Explain where a memory came from | **implemented** | Only provenance the system recorded can be shown. |
| `memory.lineage.graph` — Lineage of ancestors and descendants | **implemented** | Depth-bounded; lineage recorded by callers through parents only. |
| `memory.history.audit` — Version and event history of a memory | **implemented** |  |
| `governance.correction.preview` — Preview and apply a withdrawal, with stale-preview protection | **implemented** | Recipients outside this store report on themselves; delivery is verified only by their acknowledgement. |
| `governance.retraction.propagation` — Retraction propagates to descendants and peers | **implemented** | A peer that never acknowledges stays pending; it is shown, not forced.; Restatements of a value (notes not linked by lineage) are contested only on a revision or a withdrawal recorded as contradicted. |
| `governance.status.labels` — Status labels with stated limits | **implemented** | No label says a memory is true. |
| `governance.conflicts.preserved` — Contradictions kept as competing claims | **implemented** | Detected for structured claims and value statements; free-text disagreement can be missed. |
| `governance.action.fence` — Action-time re-check of every memory an action relies on | **implemented** | Covers tools run through the gate only. |
| `tenancy.isolation` — Tenant isolation on every access path | **implemented** | Single store; tenants share a process and its keys. |
| `context.compaction.session` — Session compaction into one governed summary | **experimental** | One summary per episode; no hierarchy. |
| `context.receipt` — Context receipts: what an agent was given, and what was excluded and why | **implemented** | Token counts are estimates (characters / 4), not a tokenizer.; Exclusions list candidates retrieval returned; memories below the relevance floor are not listed. |
| `context.map` — Governed Context Map: source-linked summaries, invalidation and a budgeted planner | **experimental** | extractive-v1 keeps every distinct fact verbatim, so it saves tokens only on restatements and chatter.; Summary nodes live in process memory and are rebuilt per process. |
| `context.decay` — Governed decay view: recent memories whole, older ones summarised, agent-written summaries | **experimental** | Pre-registered bars narrowly not met (research/results/decay-view.md), though the view beat recency on every seed.; Inspired by OptMem's published design; no OptMem code is used (upstream has no licence).; With real local models the registered bar was missed (qwen2.5:7b 0.12, llama3.1:8b 0.53 of the headroom); model summaries can pick an older real value, which the check cannot catch. |
| `versioning.branches` — Branches, commits, diff and governance-aware merge | **implemented** | No branch of a branch; merges go into main only.; Branch retrieval is the overlay view; it is not ranked by the store's retrieval arms. |
| `federation.signed` — Signed federation between stores, with key rotation | **implemented** | No consensus; each store decides for itself. |
| `privacy.erasure` — Cryptographic erasure of content | **implemented** | Backups taken before erasure hold their own copy until they expire (docs/LIMITATIONS.md). |
| `integrity.chain` — Hash-chained log with checkpoints | **implemented** | Detects rewrites against a checkpoint held elsewhere; does not prevent them. |
| `operations.dashboard` — Read-only operator dashboard | **implemented** | Read-only by design; changes go through the CLI or SDK. |
| `evaluation.release_evidence` — Release evidence and product benchmark for the exact commit | **implemented** | Synthetic corpus; one process. |
