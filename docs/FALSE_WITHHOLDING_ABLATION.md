# False-withholding diagnosis and dry-run guard ablations

Run `python -m benchmarks.false_withholding`. The benchmark locally encodes cases from the deterministic TeamWorld generator at seeds 101–105 and compares them with the recorded PR #30 aggregate reproduction. The individual PR #30 withheld rows are not present in this repository; this report does not claim an exact row-level import. It reproduces the P3b task semantics, including permitted rediscovery, and records the resulting 17.2% withholding rate (86/500) for these seeds; the historical PR #30 aggregate was 16.8%.

The frozen false-withholding corpus contains only current Memory Fabric task traces where the store still held the oracle's exact current fact but retrieval did not return it. Each row records the task/action, exact evidence IDs and text, returned IDs, blocker and lifecycle state, oracle support, and multi-label causal classification. Stale-action dry-run cases are reported separately and count toward the unsafe-action denominator.

For each case, one `ActionGate` guard is varied at a time on the same current evidence state. Audit writes are disabled and the harness checks that each dry-run leaves the evidence log watermark unchanged. The baseline actively uses the suspicious-evidence check and the `unverified` authority floor. The provisional guard is already disabled, and the certificate already requires at least one support, so those two variants are reported as placebo/no-op controls rather than claimed as effective relaxations. The report records gate releases separately from recovered tasks: an authorization change cannot itself repair an upstream retrieval miss, so retrieved-task recovery remains zero unless retrieval also returns the evidence. Each arm records recovered valid tasks, unsafe actions, Wilson 95% intervals, policy mutation and executor-call counts. No candidate rule is installed, grants are unchanged, no authorization receipt is persisted, and no action executor is called.

The result is internal deterministic simulation evidence. It is not a real-model withholding rate or a causal estimate for production traffic.
