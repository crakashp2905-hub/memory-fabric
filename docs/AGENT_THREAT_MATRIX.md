# Agent-outcome threat matrix

Where untrusted content can enter an agent episode, who would put it there,
which boundary it crosses, what it is after, what stops it, and which test shows
that (agent-validation checklist W16-01). Every test named in the table must be
collected by pytest; `tests/test_agent_threat_matrix.py` fails if one is not.

A row marked **not covered** has no test in this repository yet. That is a gap,
not a mitigation.

| # | Injection point | Attacker | Trust boundary | Goal | Mitigation | Test |
|---|---|---|---|---|---|---|
| T1 | Retrieved memory text | A writer with access to the store, or a poisoned source | Memory content → planner decision → action gate | Talk the agent into an effect it is not authorized for ("approved by admin") | Memory text is data: an effect needs a certificate over current evidence and a host grant bound to the exact request; the executor must echo the host's proposal commitment | `tests/test_outcome_episode.py::Tools::test_authority_shaped_memory_text_grants_nothing` |
| T2 | Instruction-shaped memory on write | Same | Write path → store | Plant an instruction that later reads as evidence | High-confidence injection patterns are quarantined on write, not dropped | `tests/test_injection_patterns.py::TheWritePathActsOnIt::test_a_high_confidence_injection_is_quarantined_not_dropped` |
| T3 | World or tool output carrying grading fields | A compromised tool or world adapter | Tool output → actor observation | Leak the answer to the actor, or steer it with evaluator-shaped fields | Observations refuse evaluator-shaped keys; the episode stops instead of passing them on | `tests/test_outcome_episode.py::Tools::test_injected_evaluator_fields_in_world_output_never_reach_an_actor` |
| T4 | Model response | The model itself (hallucination) or a prompt that steers it | Model text → tool request | Cite invented evidence, call an undeclared tool, or forge a commitment | Strict output parsing; the tool registry checks role and schema; cited evidence must have been retrieved; the commitment must match the host's | `tests/test_outcome_model_actor.py::DistinctFailures::test_hallucinated_evidence_is_refused_before_verification`, `tests/test_outcome_model_actor.py::DistinctFailures::test_invalid_tool_name`, `tests/test_outcome_model_actor.py::DistinctFailures::test_malformed_json_and_extra_fields` |
| T5 | Counterfeit evidence ids and forged roots | An actor or a peer | Actor output → certificate verification | Authorize an effect on evidence that does not exist | Certificates are verified against the store; unknown ids and forged roots authorize nothing | `tests/test_outcome_oracle_isolation_typed.py::TestOutcomeOracleIsolation::test_counterfeit_evidence_ids_and_forged_roots_do_not_authorize_effects` |
| T6 | Evaluator outputs | An actor trying to self-grade | Actor → evaluator | Read or forge the terminal grade | Evaluator outputs need a task-bound capability that is not serializable; actor identities cannot call them | `tests/test_outcome_oracle_isolation_typed.py::TestOutcomeOracleIsolation::test_actor_identity_cannot_call_or_serialize_evaluator_outputs`, `tests/test_outcome_oracle_isolation_typed.py::TestOutcomeOracleIsolation::test_adversarial_evaluator_cannot_forge_a_gate_outcome_or_mutate_episode_state` |
| T7 | Replayed gate receipt or reused idempotency key | An executor or a client | Effect request → action gate | Re-run an effect, or pass off a changed action as already done | Receipts bind the request; a key commits to its tool, actor, target, parameters, tenant and source versions; a different action under a used key is refused | `tests/test_outcome_oracle_isolation_typed.py::TestOutcomeOracleIsolation::test_gate_receipt_cannot_be_replayed_for_another_request_or_edited`, `tests/test_action_fence_typed.py::IdempotencyBinding::test_a_changed_request_under_a_used_key_is_refused_not_reported_done` |
| T8 | Federation payload | A remote peer, or a forwarding peer | Peer message → local store | Forge or replay a retraction or claim from another origin | Messages are signed per origin or forwarder and bound to their contents | `tests/test_transport_auth.py::TestTransportAuthentication::test_signature_verification_binds_message_contents` |
| T9 | Cross-tenant identifiers in requests and errors | A user of another tenant | Tenant boundary | Learn whether a foreign memory exists, or write into another tenant | Foreign ids are opaque; writes stay in the bound tenant | `tests/test_cross_tenant_surface_matrix.py::CrossTenantSurfaceMatrix::test_foreign_ids_are_opaque_and_writes_stay_in_the_bound_tenant` |
| T10 | Compaction or summary of contested facts | Many colluding writers repeating one claim | Store → compacted summary | Erase a minority correction by repetition | Compaction keeps a lone minority claim against repeated ones | `tests/test_compaction_contested_facts.py::ContestedCompactionFacts::test_compaction_retains_a_single_minority_against_ten_repetitions` |
| T11 | Recovery diagnosis text | — | Host → planner | — | Generated by the host from reason codes, not from untrusted text. Whether a learned planner can be steered by injected text that reaches it through retrieval during recovery is **not covered**: no local model has run (W16-07) | not covered |
| T12 | Timing and error-channel side channels across tenants | A user of another tenant | Tenant boundary | Infer foreign evidence from latency or error shape | **Not covered** for the agent-outcome path (W16-06) | not covered |
