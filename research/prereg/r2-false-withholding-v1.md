# False-withholding diagnosis and guard ablation v1

## Provenance and scope

The external PR #30 aggregate reports 16.8% valid evidence withholding over 500 tasks, reproduced at commit `d4fd174ac9056865c8b73abd857fa681daa6a0d7` against candidate `12c612ea37980f92d206fe2b343b217603d1b3cc`. The repository contains aggregate per-seed metrics and up to ten example failures per arm, not the 84 row-level withheld task records. Therefore this experiment does **not** claim to import those exact examples. It freezes a locally encoded diagnostic set from the same deterministic `teamworld` generator and labels its provenance explicitly.

## Frozen design

Use seeds 101–105, 50 agents, and all 100 task cases per seed generated by the v2 world. Compare `shared_blanket` and the current `MemoryFabric` default backend as matched arms. The diagnostic corpus contains only Memory Fabric task traces where the store still holds the oracle's exact current fact but retrieval did not return it, after the benchmark's permitted rediscovery step. Store case identity, seed, task index, question/action, oracle value, exact evidence text and memory IDs, actual blocker reason, backend miss reason, and oracle validity. Also record old evidence after correction as explicitly unsafe stale-action controls.

Classify a withheld valid case into every supported cause evidenced by its trace: retrieval/ranking, provenance/authority, independence/copy ancestry, freshness/version, poisoning/contestation, missing dependency, or other policy/lifecycle. These are multi-label causes; retain unique withheld-case denominator and report category counts and rates independently.

Counterfactuals are dry-run decisions only. Preserve the serialized live `ToolRule`, grants, and policy digest in the report. For each case, compare the actual `ActionGate.authorize` decision with cloned candidate rules that individually relax one guard (independence threshold, suspicious-evidence refusal, provisional-evidence refusal, or minimum authority). Disable gate audit writes and verify that the evidence log watermark does not move. No candidate is installed, no grant is modified, no authorization receipt is persisted, and no executor is called. Recovered task completion is distinct from a gate release: relaxing authorization cannot create retrieved evidence, so a retrieval-missed task remains unrecovered unless the read path also returns it.

Primary outcome: recovered valid action attempts and additional unsafe authorizations versus live policy, with Wilson 95% intervals. Frozen seeds and cases are paired. A result that cannot recover valid cases without unsafe actions remains a negative result; it does not promote or mutate the live policy.

All evidence is local deterministic simulation. It is not the unavailable PR #30 row-level corpus, a real-model evaluation, or authorization to execute an external effect.
