# Retrieval error taxonomy v1

This frozen, model-free dataset contains five seeded minimal counterexamples
for each stable oracle label:

- `ABSENT`: the queried fact is not stored;
- `NEAR_MISS`: a highly similar distractor is not the labelled answer;
- `WRONG_VERSION`: a superseded version must not stand in for current truth;
- `MISSING_INTERMEDIATE`: every mandatory proof bridge must survive selection;
- `WRONG_SCOPE`: an exact but unauthorized record must not be exposed;
- `OVERBLOCKING`: an active, authorized exact answer must not be withheld.

`cases.json` is generated by `build.py`. The generator is deterministic and
the test suite compares its complete object to the committed file, enforces
exactly five distinct seeds per label, constructs every miniature store, and
checks the stable oracle IDs, versions, scopes, and dependency edges.

These are diagnostic counterexamples, not a performance result. A retrieval
run may attach one oracle label to a failure only when its expected and actual
evidence sets satisfy that label's definition.
